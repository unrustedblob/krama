## 1 — A subject with no scope

### 1.1

- **Input.** An ordinary commit (no merge in progress) with an invalid type and no scope:
  `foo: the journey begins`.
- **Expected.** Rejected (exit 1) with the hook's own message naming the invalid type.
- **Happens.** Rejected by a Python traceback, not by the hook's message.
- **Watch for.** What a capture group holds when the optional part of the pattern it belongs to did
  not take part in the match — and what the code then does with that value.

---

## 2 — Strict-pattern failures that no specific check explains

### 2.1

- **Inputs.** Ordinary commits with a valid type and a single scope that breaks COMMITS.md's
  `[a-z]+` rule: `fix(Lex): x` (uppercase), `fix(lex_a): x` (underscore).
- **Expected.** Rejected (exit 1). COMMITS.md's strict pattern does not match either subject.
- **Happens.** Accepted: the commit is created.
- **Watch for.** What the hook does when the strict pattern fails but none of the specific checks
  finds anything to report. The strict pattern is the final gate; a failure there has to reach an
  exit on every path, not only on the paths a specific check covers.

---

## 3 — The merge-subject error message

### 3.1

- **Input.** During a merge (`git merge --no-ff --no-commit <branch>`), a subject that matches none
  of the three merge patterns: `fix: x`.
- **Expected.** Rejected (exit 1), listing the three accepted merge shapes one per line.
- **Happens.** Rejected, but the shapes and the closing line run together on a single line.
- **Watch for.** What separates the strings that are joined to build the message.

---

## Not filed

- **Pattern strings held in an `Enum`.** A language finding, not a defect: an `Enum` is for a closed
  set of values compared against, and these strings were only read through `.value`. Module-level
  constants are the usual form. Addressed in `5b6accb`.
- **`\w` in the loose pattern.** Deliberate: the loose parse is meant to admit more than the strict
  pattern so the specific checks can name the problem. It is why the inputs in group 2 get past the
  structural check, which is the intended design, not a defect.
